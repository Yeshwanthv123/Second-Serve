- Baseline run: **33.662 seconds**, 3 completed model responses, 30 portions to Nearby Community Kitchen.
- Preferred-partner run: **31.303 seconds**, 3 completed model responses, 20 portions to Night Shelter and 10 to Nearby Community Kitchen.
- The test approved the second plan, confirmed both fictional handoffs, and verified that the first proposal could no longer be approved.
- Full test evidence is saved locally at `artifacts/live-llm-verification.json`; a compact, credential-free extract is included in [live-llm-evidence.json](live-llm-evidence.json).

An earlier real-model attempt stopped after inventory inspection without saving a plan, and was correctly marked failed. The final implementation preserves grouped tool-call messages for the pinned SDK and adds bounded goal feedback if an LLM stops before required work is saved. The successful acceptance runs completed without that recovery step. Model responses remain generated text; saved allocations and approval validation establish the actual operational facts.

Provider tests also cover missing model weights, no silent fallback, recorded model response counts, grouped tool messages, and completion feedback. Preference tests confirm that capacity and allergen restrictions cannot be overridden. Unit tests use controlled fake responses; the acceptance check above is the real-inference evidence.

## Reproduce

```sh
# From the repository root:
docker compose up --build -d
docker compose up -d --wait backend frontend
docker compose exec -T backend python -m pytest -q tests

# With backend requirements installed locally:
python scripts/verify_http.py
python scripts/verify_container.py
python scripts/verify_live_llm.py

# Frontend component tests and compile:
cd frontend
npm ci
npm test
npm run build
```

`verify_http.py` uses isolated temporary data. `verify_container.py` intentionally creates one separate verification account in the running installation and requires working internet access to the free geocoder. Existing accounts remain untouched. After the model has been downloaded, an installation without external connectivity can use manual location entry and the real local LLM. The first model download requires internet.
